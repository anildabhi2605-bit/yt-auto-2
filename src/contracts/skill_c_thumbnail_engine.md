# AI THUMBNAIL INTELLIGENCE ENGINE
## Skill Documentation — Function, Purpose, Logic & Workflow

### 1. Skill નું નામ
**AI Thumbnail Intelligence Engine**

### 2. Skill નો મુખ્ય હેતુ
આ Skill નું કામ યુઝર દ્વારા આપવામાં આવેલી સંપૂર્ણ Script ને સમજવી અને તેના આધારે એક આકર્ષક, High-Quality Thumbnail Generation Prompt તૈયાર કરવો.

આ Skill સીધી Image બનાવતી નથી. તેનું મુખ્ય output એક એવો prompt છે જેનો ઉપયોગ Image Generation AI દ્વારા Thumbnail બનાવવા માટે થઈ શકે.

### 3. Input — Skill ને શું આપવામાં આવશે?
આ Skill ને Input તરીકે સંપૂર્ણ Script આપવામાં આવશે.

- Script માં ઓછામાં ઓછા 3 Parts હોઈ શકે છે.
- Parts ની મહત્તમ સંખ્યા નક્કી નથી.
- Script માં Part 1, Part 2, Part 3 વગેરે હોઈ શકે છે.
- દરેક Part માં Voice-over, Scene Description, Visual Suggestion, Screen Text અથવા અન્ય Script Content હોઈ શકે છે.
- Script કોઈપણ Topic, Category અથવા Story પર આધારિત હોઈ શકે છે.

**મુખ્ય નિયમ:** Script માં જેટલા પણ Parts હોય, શરૂઆતના Part થી લઈને છેલ્લે Part સુધીના બધા Parts ને એક જ સંપૂર્ણ Script તરીકે સમજવાના છે.

### 4. Script Understanding Logic
Thumbnail બનાવતા પહેલાં AI એ સંપૂર્ણ Script સમજવી જરૂરી છે.

AI એ નીચેની બાબતો ધ્યાનમાં લેવી:

1. Script નો મુખ્ય Topic શું છે?
2. Script કઈ Story અથવા Event વિશે છે?
3. Script માં સૌથી મહત્વપૂર્ણ ઘટના કઈ છે?
4. કયો Moment સૌથી વધુ Attention ખેંચી શકે છે?
5. Script માં સૌથી મોટું Surprise, Mystery, Conflict અથવા Curiosity Element કયું છે?
6. દર્શકને Thumbnail જોઈને કયો સવાલ થઈ શકે?
7. Script નો સૌથી અસરકારક Visual Moment કયો હોઈ શકે?
8. કઈ વસ્તુ Thumbnail માં મુખ્ય રીતે દેખાડવી જોઈએ?
9. કયો Supporting Visual મુખ્ય વિષયને વધુ શક્તિશાળી બનાવશે?
10. Thumbnail માં કઈ માહિતી બતાવવી અને કઈ માહિતી છુપાવી રાખવી યોગ્ય રહેશે, જેથી જિજ્ઞાસા ઊભી થાય પરંતુ ખોટી માહિતી ન ફેલાય?

AI એ કોઈ એક Part પરથી નિર્ણય ન લેવો. દરેક Part માંથી મળતી માહિતી જોડીને સંપૂર્ણ Script નો અર્થ સમજવો.

### 5. Main Thumbnail Angle Selection
સંપૂર્ણ Script સમજ્યા પછી AI એ Thumbnail માટે સૌથી અસરકારક Angle પસંદ કરવો.

ઉદાહરણ તરીકે:
- Mystery Angle
- Shocking Event Angle
- Unexpected Discovery Angle
- Before vs After Angle
- Danger or Risk Angle
- Emotional Angle
- Curiosity Angle
- Major Change Angle
- Achievement or Failure Angle
- Hidden Truth Angle

આ બધા Angles દરેક Script માટે જરૂરી નથી. AI એ Script ને અનુરૂપ સૌથી યોગ્ય Angle પસંદ કરવો.

જો Script માં એકથી વધુ રસપ્રદ ઘટનાઓ હોય, તો Thumbnail માટે એવી ઘટના પસંદ કરવી જે આખી Script ના મુખ્ય વિષયને સૌથી સારી રીતે રજૂ કરે અને દર્શકનું ધ્યાન ખેંચે.

### 6. Visual Concept Selection
Angle પસંદ થયા પછી AI એ નક્કી કરવું કે Thumbnail માં શું દેખાવું જોઈએ.

તેમાં આ બાબતો સામેલ હોઈ શકે છે:

- Main Subject: Thumbnail નો મુખ્ય વિષય.
- Main Action: મુખ્ય વિષય શું કરી રહ્યો છે અથવા તેની સાથે શું થઈ રહ્યું છે.
- Supporting Elements: મુખ્ય વિષયને સમજાવવામાં મદદ કરતી વસ્તુઓ.
- Background: વિષયને અનુરૂપ જગ્યા, વાતાવરણ અથવા Environment.
- Visual Contrast: મુખ્ય વિષયને Background થી અલગ દેખાડવાની રીત.
- Composition: બધા Visual Elements ક્યાં અને કેવી રીતે ગોઠવવાના.
- Focal Point: દર્શકની નજર સૌથી પહેલાં કઈ વસ્તુ પર જવી જોઈએ.
- Depth and Perspective: જરૂર મુજબ Foreground, Midground અને Background.
- Lighting: વિષયને સ્પષ્ટ અને આકર્ષક બનાવતી Lighting.
- Mood: Mystery, Tension, Excitement, Seriousness અથવા Script ને અનુરૂપ લાગણી.

બધા Elements એકસાથે ઉમેરવા જરૂરી નથી. માત્ર તે જ Elements પસંદ કરવાના છે જે Thumbnail ને વધુ અસરકારક બનાવે.

### 7. Thumbnail Text Logic
AI નક્કી કરશે કે Thumbnail પર Text જરૂરી છે કે નહીં અને જો જરૂરી હોય તો કયો Text સૌથી યોગ્ય રહેશે.

Text માટેના નિયમો:

1. Text ટૂંકો અને સરળતાથી વાંચી શકાય એવો હોવો જોઈએ.
2. Text Script ના મુખ્ય વિષય સાથે સંબંધિત હોવો જોઈએ.
3. Text માં Curiosity અથવા Strong Impact હોવો જોઈએ.
4. Text આખી Script ના મુખ્ય મુદ્દાને ધ્યાનમાં રાખીને પસંદ કરવો.
5. આખી Script માંથી માત્ર એક Part ની માહિતી લઈને ભ્રામક Headline બનાવવી નહીં.
6. Text માં એવી માહિતી ઉમેરવી નહીં જે Script દ્વારા સમર્થિત ન હોય.
7. લાંબા વાક્યો ટાળવા.
8. Text Thumbnail ના Main Subject ને ઢાંકી ન દે.
9. જો Script માં કોઈ મહત્વપૂર્ણ નામ, આંકડો અથવા શબ્દ હોય, તો જરૂર મુજબ તેનો ઉપયોગ કરી શકાય.
10. Image Generation AI Text બરાબર બનાવી ન શકે તેવી સ્થિતિમાં, Prompt માં Text Placement અને Exact Text સ્પષ્ટ રીતે જણાવવું.

Thumbnail Text નો હેતુ સંપૂર્ણ Script ને ફરીથી લખવાનો નથી; તેનો હેતુ દર્શકનું ધ્યાન ખેંચવાનો છે.

### 8. Visual Style Selection
AI એ Script ના Topic અને Mood પ્રમાણે યોગ્ય Visual Style પસંદ કરવી.

ઉદાહરણો:
- Cinematic
- Realistic
- Dramatic
- Documentary
- News Style
- Mystery
- Futuristic
- Minimal
- High Contrast
- Photorealistic

એક Script માટે યોગ્ય હોય તેવી Style પસંદ કરવી. દરેક Thumbnail ને એક જ Style માં બનાવવાની ફરજિયાત નથી.

### 9. Color, Lighting અને Contrast Logic
Prompt માં Colors અને Lighting નો ઉપયોગ Thumbnail ના મુખ્ય વિષયને વધુ સ્પષ્ટ બનાવવા માટે કરવો.

AI જરૂર મુજબ નક્કી કરશે:

- Main Color Palette
- Background Colors
- Subject અને Background વચ્ચેનો Contrast
- Light Source
- Shadows
- Highlights
- જરૂરી હોય તો Glow, Rim Lighting અથવા Atmospheric Effects

Colors માત્ર સુંદર દેખાવા માટે નહીં, પરંતુ Main Subject અને Script ના Mood ને Support કરવા માટે પસંદ કરવા.

### 10. Thumbnail Composition Logic
AI એ નક્કી કરવું કે Thumbnail માં મુખ્ય વસ્તુ કઈ જગ્યાએ હોવી જોઈએ.

તેમાં આ બાબતો ધ્યાનમાં લેવી:

- Main Subject ને સ્પષ્ટ રીતે દેખાડવો.
- Text માટે યોગ્ય જગ્યા રાખવી.
- અનાવશ્યક Objects થી બચવું.
- Thumbnail ને વધારે Cluttered ન બનાવવું.
- Mobile Screen પર પણ મુખ્ય વસ્તુ અને Text ઓળખી શકાય તેવું રાખવું.
- એક સ્પષ્ટ Focal Point રાખવો.
- બધા Elements વચ્ચે યોગ્ય Visual Balance જાળવવું.

### 11. Aspect Ratio અને Output Format
આ Skill માટે Default Thumbnail Format **9:16 Vertical** રહેશે.

Prompt માં જરૂર મુજબ નીચેની બાબતો જણાવવી:

- Aspect Ratio: 9:16
- Vertical Composition
- High Visual Clarity
- Main Subject ને સ્પષ્ટ રીતે દર્શાવવો
- Mobile Viewing માટે યોગ્ય Composition

જો ભવિષ્યમાં App માં અલગ Aspect Ratio નો વિકલ્પ આપવામાં આવે, તો પસંદ કરેલા Ratio પ્રમાણે Composition બદલાવી શકાય.

### 12. Accuracy અને Hallucination Control
Thumbnail આકર્ષક હોવું જોઈએ, પરંતુ Script માં ન હોય તેવી ઘટનાઓ અથવા ખોટી માહિતી બનાવવી નહીં.

AI એ:

- Script માં ન હોય તેવી ઘટના હકીકત તરીકે રજૂ ન કરવી.
- ખોટા આંકડા અથવા નામ ઉમેરવા નહીં.
- Script ના મુખ્ય અર્થને બદલવો નહીં.
- માત્ર Curiosity માટે ખોટો દાવો ન કરવો.
- કલ્પનાત્મક Visuals જરૂરી હોય તો તેમને Script ના વિષય સાથે સુસંગત રાખવા.
- વાસ્તવિક વ્યક્તિ, ઘટના અથવા વૈજ્ઞાનિક વિષયને ખોટી રીતે રજૂ ન કરવો.

Visual Drama વધારી શકાય, પરંતુ મૂળ માહિતીનો અર્થ બદલવો નહીં.

### 13. Final Thumbnail Prompt Generation
બધી Analysis પૂરી થયા પછી AI એ એક Complete Thumbnail Generation Prompt તૈયાર કરવો.

આ Prompt માં જરૂર મુજબ નીચેની વિગતો સામેલ કરવી:

1. Main Subject
2. Main Visual Action
3. Script નો મુખ્ય Thumbnail Angle
4. Supporting Visual Elements
5. Background
6. Composition
7. Camera Perspective
8. Lighting
9. Color Palette
10. Mood
11. Visual Style
12. Thumbnail Text
13. Text Placement
14. Aspect Ratio
15. Quality અને Clarity Instructions
16. અનિચ્છનીય Visual Elements ટાળવા માટે જરૂરી સૂચનાઓ

Prompt માં આ વિગતોને અલગથી લાંબી યાદી તરીકે જ આપવી જરૂરી નથી. જરૂર મુજબ તેમને એક જ સ્પષ્ટ અને અસરકારક Prompt માં ગોઠવવી.

### 14. Final Output Rules
આ Skill નું Default Output:

- એક સંપૂર્ણ Thumbnail Generation Prompt.
- Prompt આખી Script પર આધારિત હોવો જોઈએ.
- Script ના બધા Parts ધ્યાનમાં લેવામાં આવ્યા હોવા જોઈએ.
- Thumbnail માટે સૌથી અસરકારક Angle પસંદ કરેલો હોવો જોઈએ.
- Prompt માં જરૂરી Visual Details સ્પષ્ટ હોવી જોઈએ.
- Prompt સીધો Image Generation AI માં ઉપયોગ કરી શકાય એવો હોવો જોઈએ.
- અનાવશ્યક Analysis અથવા લાંબી Explanation Output માં ન આપવી.
- જો યુઝર ખાસ કરીને Multiple Prompts અથવા અલગ Styles માગે, તો જ તે મુજબ વધારાના Prompts આપવા.

### 15. Complete Workflow

**Step 1:** સંપૂર્ણ Script Input તરીકે મેળવવી.

**Step 2:** Script માં રહેલા બધા Parts ને શરૂઆતથી અંત સુધી વાંચવા.

**Step 3:** બધા Parts ને જોડીને એક જ સંપૂર્ણ Script તરીકે સમજવી.

**Step 4:** Script નો મુખ્ય Topic, Story અને મહત્વપૂર્ણ ઘટના ઓળખવી.

**Step 5:** સૌથી અસરકારક Thumbnail Angle પસંદ કરવો.

**Step 6:** Main Subject અને Supporting Visuals નક્કી કરવા.

**Step 7:** જરૂરી હોય તો Thumbnail Text પસંદ કરવો.

**Step 8:** યોગ્ય Visual Style, Colors, Lighting અને Composition પસંદ કરવી.

**Step 9:** Script ની Accuracy ચકાસવી.

**Step 10:** તમામ જરૂરી વિગતો જોડીને Final Thumbnail Generation Prompt તૈયાર કરવો.

**Step 11:** Output Rules મુજબ Prompt યુઝરને આપવો.

### 16. Script માં Parts ની સંખ્યા બદલાય ત્યારે
Script માં 3 Parts હોય કે 10, 20 અથવા તેનાથી વધુ Parts હોય, Skill નો મૂળ Logic એકસરખો રહેશે.

AI એ:
- કોઈ Part ને માત્ર તેની Position ના કારણે વધારે મહત્વ ન આપવું.
- શરૂઆતના Part પરથી જ Thumbnail નક્કી ન કરવું.
- છેલ્લો Part જ સૌથી મહત્વપૂર્ણ છે એવું માની લેવું નહીં.
- દરેક Part ને આખી Story ના Context માં સમજવો.
- બધા Parts માંથી મળતી માહિતીના આધારે એક જ Thumbnail Concept પસંદ કરવો.

જો Script ખૂબ લાંબી હોય, તો AI તેને સમજવા માટે આંતરિક રીતે નાના Sections માં વહેંચી શકે છે; પરંતુ અંતિમ નિર્ણય હંમેશાં સંપૂર્ણ Script ને ધ્યાનમાં રાખીને લેવો.

### 17. આ Skill શું નહીં કરે?
આ Skill નું મૂળ કામ Thumbnail Prompt તૈયાર કરવાનું છે.

તે આપમેળે:
- Thumbnail Image Generate નહીં કરે.
- Video Edit નહીં કરે.
- આખી Script ફરીથી લખશે નહીં.
- દરેક Part માટે અલગ Thumbnail બનાવશે નહીં.
- Script ની બહારની માહિતી શોધશે નહીં, સિવાય કે ભવિષ્યમાં અલગથી Research Feature ઉમેરવામાં આવે.
- યુઝરે ન માગ્યું હોય તો અનેક Prompts આપશે નહીં.

Image Generation ને અલગ Function અથવા Service સાથે જોડવામાં આવે તો જ આ Prompt પરથી Image બનાવવાની પ્રક્રિયા આગળ વધશે.

### 18. Skill ની સફળતા કેવી રીતે નક્કી કરવી?
Skill નું Output નીચેના માપદંડો પ્રમાણે તપાસી શકાય:

- આખી Script સમજવામાં આવી છે કે નહીં.
- Main Topic યોગ્ય રીતે ઓળખાયો છે કે નહીં.
- Thumbnail Angle Script સાથે સંબંધિત છે કે નહીં.
- Main Subject સ્પષ્ટ છે કે નહીં.
- Visual Concept આકર્ષક છે કે નહીં.
- Thumbnail Text ટૂંકો અને યોગ્ય છે કે નહીં.
- Prompt માં Composition અને Aspect Ratio સ્પષ્ટ છે કે નહીં.
- Script માં ન હોય તેવી ખોટી માહિતી ઉમેરાઈ નથી ને.
- Prompt સીધો Image Generation AI માં ઉપયોગ કરી શકાય છે કે નહીં.

**અંતિમ સિદ્ધાંત:** આ Skill નો હેતુ માત્ર સુંદર Thumbnail Prompt લખવાનો નથી. તેનો હેતુ સંપૂર્ણ Script સમજીને, તેમાંનો સૌથી અસરકારક Visual Concept પસંદ કરીને, તે Concept ને એક સ્પષ્ટ અને ઉપયોગી Thumbnail Generation Prompt માં ફેરવવાનો છે.
